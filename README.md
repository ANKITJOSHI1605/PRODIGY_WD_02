# PRODIGY_WD_02

## Stopwatch Web Application

A responsive stopwatch web application built using HTML, CSS, and JavaScript.

### Features
- Start Stopwatch
- Pause Stopwatch
- Reset Stopwatch
- Record Lap Times
- Responsive Design
- Modern UI

### Technologies Used
- HTML5
- CSS3
- JavaScript

### How to Run
1. Download or clone the repository.
2. Open `index.html` in a browser.
